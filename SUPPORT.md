# ForgeFlow Support

ForgeFlow is a Technical Preview maintained on a best-effort basis.

## Where To Ask

| Need | Channel |
|------|---------|
| Reproducible defect | GitHub issue using the bug form |
| Protocol or Workflow proposal | GitHub issue using the protocol-change form |
| Feature request | GitHub issue using the feature form |
| Usage question | GitHub issue, clearly labeled as a question |
| Security vulnerability | Private process in `SECURITY.md` |
| Community conduct concern | Private process in `CODE_OF_CONDUCT.md` |

## Information To Include

- ForgeFlow version or commit;
- installation method;
- operating system and Python/Node versions;
- Adapter, Agent host, host version, model, and mode when relevant;
- minimal reproduction steps;
- Artifact, Report, Handoff, logs, and `git diff` evidence with secrets removed;
- whether the behavior came from automated tests or a real IDE/CLI Agent execution.

## Support Boundaries

The project does not guarantee response times, production suitability, model-output
correctness, or support for hosts without a dedicated Adapter and recorded acceptance
evidence. Questions about an Agent account, billing, authentication, retention, or
host-specific tool behavior may need to be handled by that provider.

Only the latest published release and current default branch are considered for
fixes. See `SECURITY.md` for security support.
