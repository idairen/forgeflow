# ForgeFlow Roadmap

This roadmap communicates direction rather than committed dates or current
capabilities. Implemented behavior is defined only by the repository's normative
framework and released code.

## Current: Public Alpha Readiness

- align security, contribution, support, and governance documentation;
- validate installable Python and npm release artifacts;
- record critical real-host acceptance evidence for Codex and GitHub Copilot;
- establish repeatable version, Changelog, Tag, and GitHub Release practices;
- keep the Agent-agnostic Core distinct from host-specific Adapter claims.

## Next: Protocol Reliability

- expand regression coverage for scope isolation, Return, Recovery, incremental
  change, evidence history, and plugin Review behavior;
- publish an acceptance matrix tied to specific Adapter and host versions;
- improve migration guidance as protocol versions evolve;
- provide a complete, reproducible end-to-end example.

## Later: Ecosystem Growth

- document a stable Adapter contribution contract;
- evaluate additional Agent hosts without claiming support before acceptance;
- improve protocol validation and release provenance;
- consider a documentation site and reusable community Review plugins.

Roadmap proposals should be opened as GitHub issues and evaluated through
`GOVERNANCE.md`.
