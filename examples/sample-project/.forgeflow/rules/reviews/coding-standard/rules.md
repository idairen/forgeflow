# Coding Standard Review Rules — Sample

## Overview

Checks code style, naming conventions, and PEP8 compliance for Python projects.

| Rule ID | Description | Check Criteria | Expected Result |
|---------|-------------|----------------|-----------------|
| CST-001 | No trailing whitespace | Scan all .py files for trailing spaces at end of lines | Lines trimmed clean |
| CST-002 | Docstring on public functions | Check that all module-level functions have docstrings | At least one-line description |

## Notes

- Modify the rules table to match your team's coding standards.
- Add `CST-XXX` prefix for custom rule IDs.
