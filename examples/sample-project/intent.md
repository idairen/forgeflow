# Sample Project Intent

Build a task-management HTTP API for a small engineering team.

The first release must provide:

1. user authentication with expiring access tokens;
2. task creation, reading, updating, and deletion;
3. assignment of tasks to authenticated users.

The first release excludes mobile clients, billing, and third-party identity
providers. The API implementation language, web framework, persistence technology,
and deployment environment remain engineering decisions for Solution.
